# callone 서버(RTX 4090) 실시간 통화 — 서빙 전용 의존성.
#
# ⚠️ requirements-heavy.txt / pip install -e ".[heavy]" 와 절대 같은 venv 에 섞지 마라.
#    heavy 는 데이터 파이프라인(화자분리/학습)용이라 서빙 환경과 분리한다.
#    4090 은 "서빙 전용". 분리/학습은 A100 에서 이미 끝났다(별 venv).
#
# LLM 은 여기 없다 → llama-server(컴파일된 별도 바이너리)로 HTTP 서빙(파이썬 의존성 0, 충돌 0).

#
# ── 설치 순서 (반드시 이 순서, scripts/setup_serve_gpu.sh 가 자동화) ─────────────
# 0) ffmpeg (브라우저 마이크 opus/webm 변환):  apt install -y ffmpeg
# 1) torch 를 CUDA 인덱스에서 먼저(ASR CUDA 라이브러리 정합):
#      pip install --index-url https://download.pytorch.org/whl/cu124 torch torchaudio
# 2) callone 코어(폴백 배관, heavy 아님):  pip install -e .
# 3) 이 파일:  pip install -r requirements-serve-gpu.txt
# 4) numpy 핀 재확인(librosa/numba 가 2.4 로 올리면 깨짐 — 반드시 마지막):  pip install "numpy<2.4"
