# ⚠️ requirements-heavy.txt / pip install -e ".[heavy]" 와 절대 같은 venv 에 섞지 마라.
#    heavy 는 데이터 파이프라인(화자분리/학습)용이라 transformers<4.50 + pyannote 3.x +
