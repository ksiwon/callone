# 4. 휴대폰에서 clone과 통화하기

휴대폰 통화는 두 가지 방식. **A(권장)** 가 쉽다.

---

## A. 하이브리드 (폰은 화면만, 모델은 컴퓨터가) ← 권장
폰은 **웹 통화 화면**만 열고, 실제 계산은 같은 네트워크의 컴퓨터(노트북/GPU 서버)가 한다.

### 1) 컴퓨터에서 서버 띄우기
```bash
callone-serve                 # :8000  (모델 있는 컴퓨터에서)
cd ui && npm run dev -- --host    # :5173, --host = 외부기기 접속 허용
```

### 2) 컴퓨터 IP 확인
```powershell
ipconfig        # IPv4 주소 (예: 192.168.0.10)
```

### 3) 폰 브라우저에서 접속
- 폰과 컴퓨터가 **같은 와이파이**인지 확인
- 폰 브라우저 → **http://192.168.0.10:5173**
- 화자 선택 → 통화 (마이크 권한 허용)

> 방화벽이 막으면 5173/8000 포트 허용. HTTPS 필요 시 `ngrok http 5173` 같은 터널 사용.

---

## B. 완전 온디바이스 (오프라인, 폰 자체에서)
인터넷 없이 폰만으로. 가장 어렵고 **추가 변환 작업 필요**.

- LLM: Gemma 4 **E4B/E2B + QAT** → **Ollama**(안드로이드 termux) / **MediaPipe LLM** / iOS **MLX**
- 목소리: per-speaker **Piper/MeloTTS** 경량본을 폰에 탑재
- ASR: Whisper small 또는 Gemma 오디오

`models/llm_e4b/`, `models/tts_phone/` 를 각 런타임 포맷(LiteRT/ggml)으로 변환해 앱에 넣어야 한다.
→ 일상 대화 수준이면 **A 방식으로 충분**. 온디바이스는 프라이버시가 꼭 필요할 때.

---

## 요약
- 그냥 쓰고 싶다 → **A** (컴퓨터에서 `callone-serve` + `npm run dev -- --host`, 폰 브라우저로 접속)
- 완전 오프라인 → **B** (모델 폰 탑재, 추가 변환 필요)
