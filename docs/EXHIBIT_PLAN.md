# 졸업전시 기획서 — 《여보세요, 나야》 (가제)

산업디자인 졸업전시용 callone 전시 기획. 2026-07 초안.

---

## 0. 왜 이 시스템이 전시가 되는가

callone 의 기술적 성질이 그대로 전시 언어가 된다:
- **제로샷 10초** → 관람객이 그 자리에서 참여 가능(사전 준비 0)
- **ephemeral(끊으면 소멸)** → "목소리는 태어나고, 통화가 끝나면 사라진다" — 형태와 의미의 일치
- **실시간 통화** → 스크린 데모가 아니라 **몸의 경험**(수화기를 든다)
- **로컬 처리** → "당신의 목소리는 이 방을 떠나지 않습니다" — 프라이버시가 연출이 됨

## 1. 콘셉트 후보 3 (추천: A)

### A. 《여보세요, 나야》 — 나에게서 걸려온 전화 ★추천
관람객이 부스에서 **10초간 자기 목소리를 녹음**하면, 잠시 후 부스의 전화가 울린다.
수화기를 들면 — **자기 목소리가 말을 건다.** 1~2분 대화. 끊는 순간 그 목소리는 소멸한다.

- 경험의 질문: "내 목소리가 나 없이 말할 때, 그것은 나인가?" (AI 클론·정체성 담론 — HCI 문헌의 Mirror/도플갱어 논의를 대중 경험으로 번역)
- **권리 문제 원천 차단**: 관람객 본인 목소리만 사용, 본인 동의(이미 구현된 동의 게이트), 즉시 소멸(이미 구현된 cleanup_session)
- 회전율: 1인 ~3분 → 시간당 15~20명. 졸전 규모에 적합

### B. 《부재중 전화》 — 그리운 목소리
사전 협력 가족 1~2팀(동의서)과 만든 실제 사례 중심. 관람객은 다큐 영상+제한적 체험.
감정적 임팩트 최상이나 **윤리 심사·연출 난도 높음**. A의 서사 벽면 요소로 축소 채용 권장.

### C. 《목소리 유산》 — 서비스 디자인 프레임
통화 녹음→화자분리→목소리 보관까지의 "의례"를 키오스크 서비스로 제안. 담론성은 좋으나
체험 강도가 약함. 도록/패널 스토리로 흡수 권장.

**최종안: A를 본 체험으로, B를 벽면 서사(왜 이 기술이 존재하는가)로, C를 도록 텍스트로.**

## 2. 관람객 여정 (1사이클 ≈ 3분)

```
[진입] 부스 밖: "10초를 빌려주세요" 사인 + 대기줄 라인
  ↓
[동의] 태블릿: 본인 목소리 사용 동의(구현돼 있는 체크 게이트) + "끊는 순간 삭제됩니다"
  ↓
[녹음] 수화기에 대고 주어진 문장 낭독 10초 (예: "여보세요, 나야. 잘 지냈어?")
  ↓  (~15s: 제로샷 ref 세팅 + CUDA graph 예열 — init_session 이 이미 이 구조)
[벨소리] 부스의 옛날 전화기가 울린다  ← 경험의 정점(놀람)
  ↓
[통화] 자기 목소리와 1~2분 대화. 페르소나: "10년 뒤의 나" (캐릭터 카드로 구현)
  ↓
[작별] 시간 다 되면 클론이 먼저 작별 인사(구현된 farewell) → "삭제되었습니다" 조명 연출
  ↓
[여운] 리플렉션 카드 1장: "방금 당신과 통화한 것은 누구였나요?" + 벽면 카운터
       "오늘 ___개의 목소리가 태어나고 사라졌습니다"
```

## 3. 물리 설치 (산업디자인 산출물)

| 요소 | 설계 |
|---|---|
| **부스** | 1인용 반밀폐 부스(1.2×1.2×2.2m), 흡음재 내장 — 전시장 소음 차단 + 사적 공간 연출. 외부는 대기자가 실루엣만 보이는 반투명 |
| **전화기** | 로터리 다이얼 전화기 개조(핵심 아티팩트) — 수화기 마이크/스피커를 USB 오디오로 교체, 후크 스위치 = 통화 시작/종료 트리거, 내부에 진짜 벨(솔레노이드) |
| **조명** | 통화 상태 연동(구현된 state 이벤트): 대기=호박색, 벨=점멸, 통화=따뜻한 백색, 삭제=짧은 소등→리셋 |
| **카운터** | 벽면 닉시튜브/세그먼트 — 소멸된 목소리 수 |
| **패널** | 파이프라인 다이어그램(10초→분리→합성→소멸), B 서사(가족 사례), 윤리 스테이트먼트 |

수화기 = 지향성·밀착 마이크라 **전시장 소음 문제를 형태가 해결**한다(헤드셋 데모의 어색함 제거).

## 4. 기술 매핑 (이미 있는 것 vs 만들 것)

**이미 있음**: 제로샷 클론(10초)·실시간 통화·barge-in·farewell(작별 인사)·동의 게이트·
cleanup_session(즉시 소멸)·상태 이벤트(조명 연동용)·워밍업·폴백 체인·캐릭터 카드("10년 뒤의 나").

**전시 모드로 만들 것**:
1. **키오스크 플로우**: 위저드 → 단일 화면 자동 진행(동의→녹음→벨→통화→리셋), 무인 루프
2. **후크 스위치/벨 연동**: 라즈베리파이 GPIO 또는 아두이노 → WS 제어 메시지(수화기 들면 세션 시작)
3. **통화 시간 제한**(90~120s) + farewell 자동 트리거
4. **소멸 카운터 API**(세션 종료 수 집계 — 개인데이터 아님)
5. **운영 안정화**: 아침 run_all 원버튼, 장애 시 "잠시 쉬는 중" 화면, 하루 리허설 체크리스트

**하드웨어**: 로컬 GPU 박스(3090급, 전시장 네트워크 불신 → 오프라인 동작이 원칙) + 예비 노트북(cpu 티어 폴백). 예산: GPU 중고 박스 ~150만, 부스 목공/흡음 ~80만, 전화기 개조 ~15만, 조명/전장 ~20만.

## 6. 윤리·운영 원칙 (심사 방어 겸)

- 본인 목소리만, 명시 동의, 즉시 삭제(기술적으로 실제 그러함 — 시연 가능)
- 미성년 관람객: 보호자 동의 or 체험 제한
- "AI 음성" 상시 고지(구현된 배지의 물리 버전: 부스 내 문구)
- 심리적 안전: 작별 인사로 끝맺음(구현됨), 불편 시 즉시 후크(끊기) = 물리적 통제권
- 데이터 보관 0 이 검증 가능한 구조(로컬·오픈소스) — 심사 질문에 코드로 답변 가능

## 7. 이 전시가 주장하는 것 (스테이트먼트 초안)

> 우리는 목소리를 남기는 시대를 산다. 그러나 남는 것과 사는 것은 다르다.
> 《여보세요, 나야》는 10초의 목소리로 태어나 3분을 살고 사라지는 존재를 만든다.
> 수화기를 내려놓는 순간의 상실감 — 그것이 이 기술이 우리에게 물어야 할 질문이다.

전시 후 확장: 졸전 아카이브 → HCI 연구(docs 연구방향의 RQ1/RQ4 파일럿 데이터로 연결 가능,
관람객 리플렉션 카드 = 질적 데이터), 또는 CHI Interactivity 출품.
