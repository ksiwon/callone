# 졸업전시 기획서 — 《여보세요, 나야》 (3트랙 확정판)

산업디자인 졸업전시용 callone 전시 기획. 2026-07 개정 2판.
전제: 모든 참가자는 사전 동의 확보됨(본인 목소리·지참 녹음 모두). 윤리 리스크 논외.

---

## 0. 한 문장

> **목소리는 10초면 온다. 말투는 한 통의 녹음, 기억은 백 시간.**

데이터가 쌓일수록 "그 사람"이 되어가는 과정을 세 번의 통화로 체험시킨다.
근거(벽면 텍스트 겸): 스탠퍼드 1,052명 연구 — 인구통계만 74% → 설문 82% → 인터뷰 결합 86%,
이후 수렴(asymptote). 데이터 축 = 충실도 축 = 전시 동선 축.

## 1. 전시 구조 = 3트랙

| | ① 《나》 | ② 《그 사람》 | ③ 《온전히》 |
|---|---|---|---|
| 데이터 | 현장 10초 녹음 + 1분 설문 | 녹음 파일 한 통(지참) | 사전 수집 수십 시간 + 심층 인터뷰 |
| 목소리 | 제로샷(즉석) | 화자분리→최적 ref 추출 | 제로샷 ref 다중 + 품질 선별 |
| 페르소나 | 설문→캐릭터 카드 즉석 생성 | 전사 기억 추출 + 관계 설문 | LoRA 말투 튜닝 + 기억 RAG 풀 |
| 통화 상대 | 10년 뒤의 나 | 소중한 사람 | 협력자의 완전한 클론 |
| 운영 | 워크인 전원, 4분 회전 | 예약 슬롯(하루 4~6팀), 15분 | 사전 제작 사례, 상영+블라인드 체험 |
| 끝맺음 | 소멸(카운터) | 소멸 or USB 반출 선택 | 리빌(실제 인물 공개) |

관람 동선 = 데이터 역순 진입: 입구에서 ③ 완성형을 목격 → ① 씨앗을 직접 체험 → ② 자기 것을 심고 감.
(혼잡 시 ①만 체험해도 완결되도록 각 트랙 독립 완결.)

## 2. 트랙 ① 《나》 — 10년 뒤에서 걸려온 전화 (메인, 워크인)

```
[동의·설문] 태블릿 90초: 동의 체크 → 설문 6문항
  ↓
[녹음] 수화기에 문장 낭독 10초 ("여보세요, 나야. 잘 지냈어?")
  ↓  ~15s: ref 세팅+워밍업, 설문→캐릭터 카드+memories 시드 생성
[벨] 전화가 울린다
  ↓
[통화] 90~120초. "10년 뒤 나" — 설문 답을 아는 상태로 말 걸어옴
  ↓
[작별] 시간 종료 → farewell 자동 → 마지막에 부메랑 연출(아래)
  ↓
[소멸] 조명 소등→리셋, 벽면 카운터 +1, 리플렉션 카드 1장
```

**설문 6문항** (연구 근거: GSS류 가치관 + TIPI 축약 + 개인 앵커):
1. 요즘 가장 큰 고민 하나 (단답)
2. 10년 뒤 나는 어디서 무엇을 하고 있을까 (한 문장)
3. 가장 아끼는 사람 (호칭만)
4. 성격 슬라이더 2개: 내향↔외향 / 신중↔즉흥
5. 요즘 나를 웃게 한 것
6. **10년 뒤 나에게 남기는 한마디** (자유 입력)

**부메랑 연출**: 6번 답을 클론이 작별 직전에 되돌려준다 —
"아 맞다. 네가 나한테 하고 싶은 말 있었잖아. …나도 너한테 똑같이 말해주고 싶었어."
설문이 곧 대본 재료가 되는 구조. 페르소나 생성 = 캐릭터 카드 템플릿 채움 + memories.json 시드
(1·2·3·5번 → "사용자는 …" 문장으로 변환, 기존 RAG가 그대로 회상).

회전율: 1인 ~4분, 시간당 12~15명. 부스 2기 운영 시 25~30명.

## 3. 트랙 ② 《그 사람》 — 한 통의 녹음 (예약제)

참가자가 소중한 사람과의 통화 녹음 파일 하나를 가져온다(USB/폰). 하루 4~6팀 예약.

```
[접수] 예약 확인 → 파일 투입
  ↓
[분석 3~5분] 화자분리→ref 후보 추출(voice_analyze 구현됨)
  — 대기시간 자체를 연출: "목소리를 찾고 있습니다" 파형 시각화 스크린
  ↓
[선택] 화자 카드에서 "이 목소리가 그 사람인가요?" 샘플 듣고 선택(구현됨)
  ↓
[관계 설문 2분] 태블릿 8문항: 서로 부르던 호칭 / 그 사람 말버릇·자주 하던 말 /
  함께한 기억 2~3개 / 마지막으로 나눈 대화 주제 / 그 사람이 나를 놀리던 방식
  ↓  전사 기억 자동 추출(memory_update) + 설문 → memories.json 병합
[통화] 3~5분. barge-in 허용, 시간 여유 있게
  ↓
[선택의 순간] "이 목소리를 가져가시겠습니까?"
  — 소멸(기본) or 본인 USB로 반출(구현된 export). 우리 쪽 보관은 어느 쪽이든 0
  ↓
[여운] 리플렉션 카드 + (동의 시) 한 줄 소감 벽면 게시
```

관계 설문의 역할: 전사에서 안 나오는 관계 고유 신호(호칭·장난)를 주입 — IMPersona 연구가
보인 "말투+개인지식 결합"이 지인 설득의 핵심이라는 결과를 그대로 적용.

## 4. 트랙 ③ 《온전히》 — 백 시간의 사람 (사전 제작)

협력자 1~2명과 여름 동안 제작하는 완성형 사례. 전시장에서는 "만들어진 결과"를 만난다.

**제작 파이프라인** (8~9월):
1. 녹음 수집: 일상 통화·대화 수십 시간 → diarize → utterances/parquet
2. 심층 인터뷰: AVP 프로토콜 변형 2시간 — **callone 자신이 AI 인터뷰어**로 전화를 걸어 진행
   ("클론이 스스로 물어보며 자란다" — 제작 과정 자체가 다큐 소재)
3. 말투: LoRA 튜닝(배선 완료) + 기억: memories 대량 구축 + RAG
4. 검증: bench + 가족 블라인드 청취

**전시 형태**:
- **다큐 영상(4~5분)**: 협력자 실제 모습 + 제작 과정 + "클론과 처음 통화한 날" 반응
- **블라인드 통화 체험(예약/오픈 슬롯)**: 관람객이 협력자의 클론과 3분 통화 → 끊은 뒤
  질문 한 장: "방금 상대는 사람이었을까요?" → 실제 협력자 영상으로 리빌
- 벽면 스탯: "문자 기록으로 학습한 클론, 지인의 44%가 사람으로 오인했다(IMPersona, 2025)"

③이 있어야 ①·②가 "시작"으로 읽힌다 — 10초짜리 체험의 끝에서 "백 시간이면 어디까지 가는가"를
목격시키는 것이 전시의 논지.

## 5. 공간·물리 설치

| 요소 | 설계 |
|---|---|
| 배치 | 입구 ③ 상영 코너 → 중앙 ① 메인 부스(가능하면 2기) → 출구 측 ② 접수 데스크+부스 1기. ③ 블라인드 체험은 ② 부스를 오프피크 공유 |
| 부스 | 1인 반밀폐(1.2×1.2×2.2m), 흡음재, 반투명 외피(대기자에게 실루엣만) |
| 전화기 | **시대 그라데이션**: ① 현대 미니멀 핸드셋 → ② 90년대 가정용 무선전화기 → ③ 로터리 다이얼 — 데이터가 깊어질수록 기억도 오래된 물건으로. 셋 다 후크 스위치=트리거, USB 오디오 개조 |
| 조명 | 상태 연동(state 이벤트): 대기=호박색, 벨=점멸, 통화=따뜻한 백색, 소멸=소등→리셋 |
| 카운터 | 벽면: "오늘 ___개의 목소리가 태어나고 사라졌습니다" (①·② 합산) |
| 패널 | 데이터→충실도 그라데이션 그래프(74→82→86%), 파이프라인 다이어그램, 스테이트먼트 |

수화기 = 밀착 마이크 — 전시장 소음 문제를 형태가 해결.

## 6. 기술: 있는 것 / 만들 것

**이미 있음**: 제로샷 클론(10초)·실시간 통화·barge-in·farewell·cleanup(소멸)·상태 이벤트·
워밍업·폴백 체인·voice_analyze(화자분리→ref 추출→화자 카드)·memory_update(전사→기억)·
RAG 회상(auto)·LoRA 배선·import/export·캐릭터 카드.

**만들 것** (괄호=사용 트랙):
1. **설문→페르소나 모듈**: 답변→캐릭터 카드 템플릿+memories 시드 (①②) — 핵심 신규
2. 키오스크 자동 플로우: 동의→설문→녹음→벨→통화→리셋 무인 루프 (①)
3. 통화 시간제한+farewell 자동 트리거+부메랑 대사 주입 (①③)
4. analyze 전사→memory_update 자동 배선 (②)
5. 후크/벨 GPIO 연동(라즈베리파이→WS 제어) (전체)
6. 소멸 카운터 API (①②)
7. AI 인터뷰어 모드: AVP 변형 질문 스크립트로 callone이 인터뷰 진행 (③ 제작용)
8. 운영 안정화: 원버튼 기동, 장애 화면, 8h 내구 (전체)

**하드웨어**: 로컬 GPU 박스(3090급, 오프라인 원칙) + 예비 노트북(cpu 티어).
예산: GPU 박스 ~150만, 부스 목공/흡음 ~80만, 전화기 3종 개조 ~25만, 조명/전장 ~20만, 상영 ~15만.

## 8. 스테이트먼트 초안

> 우리는 목소리를 남기는 시대를 산다. 그러나 남는 것과 사는 것은 다르다.
> 《여보세요, 나야》는 10초, 한 통, 백 시간 — 세 개의 시간으로 사람을 빚는다.
> 수화기를 내려놓는 순간, 어떤 목소리는 사라지고 어떤 목소리는 남는다.
> 무엇을 남길지 정하는 것은 기술이 아니라 당신이다.

전시 후 확장: ① 리플렉션 카드+③ 블라인드 응답 = 질적 데이터 → HCI 연구 RQ1/RQ4 파일럿,
CHI Interactivity 출품 경로 유지.
