# 3. 노트북에서 clone과 통화하기

> 학습 끝난 모델로 **노트북에서 실시간 통화**. 대상: Intel Arc iGPU(예: 갤럭시북5 Pro / Arc 140V).
> 스택: **Qwen3.5-4B + LoRA(말투) → llama.cpp(별도 프로세스, HTTP) + Piper(화자 A 목소리, onnx) + faster-whisper(ASR)**.
>
> ⚠️ 왜 이 구조? OpenVINO 는 Qwen3.5(qwen3_5) 변환을 아직 못 한다(optimum-intel #1628).
> 그래서 LLM은 **llama.cpp 로 띄우고 우리 파이썬은 HTTP로만 호출** → torch/OV 충돌(segfault)도 원천 차단.

준비물(서버/GPU에서 만든 산출물):
- LoRA 어댑터: `models/llm_phone/{A,B}/checkpoint-90/` (말투 학습본)
- 페르소나·RAG: `data/speakers/{A,B}/` (profile.json, utterances.json)
- 화자 A 목소리: `models/tts_piper/{A,B}.onnx` (+ `.onnx.json`) — [5. 화자 A 목소리 학습](5_화자A_목소리_학습.md)

---

## 1) llama.cpp 받기 (1회)
- **바이너리**: GitHub Releases 의 `llama-bXXXX-bin-win-vulkan-x64.zip` → `C:\tools\llama.cpp\`
- **소스(변환 스크립트용)**: `git clone https://github.com/ggml-org/llama.cpp C:\tools\llama.cpp-src`

## 2) LoRA → 단일 GGUF (1회) — `scripts/make_gguf.py`
LoRA를 base에 **병합**해 GGUF로 굽는다. (qwen3_5 는 멀티모달이라 `AutoModelForCausalLM`이
텍스트 모델을 뽑아냄 → LoRA와 정확히 매칭. make_gguf가 MTP 레이어도 자동 처리.)
```powershell
pip install torch peft "transformers>=5.10"
# fp16 base 받기(병합에 필요, ~9GB, 1회)
hf download Qwen/Qwen3.5-4B --local-dir models_base\qwen3.5-4b
# 병합 → f16 GGUF
python scripts\make_gguf.py --speaker A --base models_base\qwen3.5-4b `
    --llama-cpp C:\tools\llama.cpp-src --quant f16 --keep-merged
# Q4 양자화(속도)
C:\tools\llama.cpp\llama-quantize.exe models_gguf\qwen3.5-4b-A-f16.gguf `
    models_gguf\qwen3.5-4b-A-Q4_K_M.gguf Q4_K_M
```
→ 배포 모델 `models_gguf\qwen3.5-4b-A-Q4_K_M.gguf` (~2.6GB). 끝나면 base/f16/merged는 지워도 됨.

## 3) llama-server 띄우기 (별도 터미널, 통화 중 계속 켜둠)
```powershell
$env:GGML_VK_DISABLE_COOPMAT = "1"      # Arc 140V Vulkan TDR 회피
C:\tools\llama.cpp\llama-server.exe -m models_gguf\qwen3.5-4b-A-Q4_K_M.gguf `
    -ngl 99 -c 4096 --host 127.0.0.1 --port 8080
```
- GPU 불안정하면 `-ngl 0`(CPU, 안 죽지만 느림). 더 빠른 SYCL은 Intel IPEX-LLM llama.cpp 포터블.
- `http://127.0.0.1:8080/health` 가 `ok` 면 준비됨.

## 4) 화자 A 목소리 배치
`models/tts_piper/A.onnx` + `A.onnx.json` 두면 자동 인식. 없으면 placeholder(beep)로 폴백(루프 확인용).
```powershell
pip install piper-tts sounddevice      # Piper 추론 + 마이크
```

## 5) 통화
**A. 간단 — 마이크 CLI**
```powershell
python scripts\call_mic.py --speaker A
# [Enter] 누르고 말하기 → 끝나면 [Enter] 다시 → 화자 A 응답(목소리)
```
**B. 브라우저 UI**
```powershell
callone-serve          # 터미널1: http://localhost:8000 (llm.backend=auto → 8080 자동 감지)
cd ui && npm install && npm run dev    # 터미널2: http://localhost:5173
```

## 동작 / 튜닝
- 흐름: 마이크 → faster-whisper(한국어) → **Qwen3.5-4B+LoRA(화자 A 말투)** → Piper(화자 A 목소리) → 스피커.
- 설정은 `configs/serve.yaml` `llm:` 에서:
  - `use_rag: false` (기본) — LoRA가 말투 내재화 → 일상대화엔 RAG 끄는 게 자연스러움(삼천포 방지). 사실 기억 필요하면 `true`.
  - `temperature: 0.5`, `max_new_tokens: 80` — 전화 톤(짧고 덜 산만). 반복 루프는 repeat_penalty로 억제됨.
- ASR이 CPU라 느리면 `asr.model: small` 로 낮추면 빨라짐(정확도 약간↓).

## 빠른 점검(LLM만)
```powershell
$body = @{messages=@(@{role='user';content='화자 A 나 왔어'});max_tokens=80;chat_template_kwargs=@{enable_thinking=$false}} | ConvertTo-Json -Depth 6
$bytes=[Text.Encoding]::UTF8.GetBytes($body)
(Invoke-RestMethod -Uri http://127.0.0.1:8080/v1/chat/completions -Method Post -ContentType 'application/json; charset=utf-8' -Body $bytes).choices[0].message.content
```
경상도 말투("마/~노/~나/아이가")가 나오면 LoRA 적용 성공.
