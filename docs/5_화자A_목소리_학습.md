# 5. 화자 A 목소리 학습 (Piper TTS, GPU)

> 화자 TTS 데이터셋으로 **그 사람 목소리** Piper 모델을 학습 → onnx → 노트북 CPU 실시간 합성.
> 추론은 노트북(onnx, torch 불필요)이지만 **학습은 CUDA GPU 필요**(Arc/CPU는 비현실적).

상세 명령은 [`scripts/train_piper.md`](../scripts/train_piper.md) · 환경셋업 [`scripts/setup_piper_gpu.sh`](../scripts/setup_piper_gpu.sh).

## 흐름
1. **(노트북) 데이터셋 변환** — GPU 불필요
   ```powershell
   pip install soundfile soxr scipy
   python scripts\prep_piper.py --speaker A      # data/datasets/A/tts → piper_ds\A (22050Hz, id|text)
   Compress-Archive -Path piper_ds\A -DestinationPath piper_ds_A.zip -Force
   ```
2. **(GPU, 예: Elice A100 / VSCode+CUDA 이미지)** `piper_ds_A.zip` + `scripts/setup_piper_gpu.sh` 업로드 후:
   ```bash
   unzip piper_ds_A.zip -d ~/piper_ds
   bash setup_piper_gpu.sh && source ~/piper-train/bin/activate
   # preprocess(한국어 음소) → train(lessac에서 파인튜닝) → train_piper.md 참고
   ```
   - **tmux 안에서 학습** (`tmux new -s piper`) — 세션 끊겨도 유지. ⚠️ 인스턴스 stop 하면 죽음(최신 체크포인트에서 재개).
   - `--checkpoint-epochs 100` + onnx watcher 로 100 epoch마다 `~/onnx_snaps/A_*.onnx` 자동 누적(train_piper.md 의 watcher).
3. **품질은 귀로** — `~/onnx_snaps`의 여러 epoch 합성해 비교, best 채택(후반이 항상 낫진 않음/과적합).
   ```bash
   echo "화자 A 나 밥 묵었나" | piper -m ~/onnx_snaps/A_3500.onnx -c ~/onnx_snaps/A_3500.onnx.json -f /tmp/t.wav
   ```
4. **(노트북)** best onnx → `models\tts_piper\A.onnx` + `A.onnx.json` → [3. 노트북에서 통화](3_노트북에서_통화.md).

## 환경 핀(중요 — 안 맞으면 설치 실패)
Piper 학습 스택은 구버전이라 정확한 핀 필요(`setup_piper_gpu.sh`에 박혀있음):
- **Python 3.10**, **pip<24.1**(PL 1.7.x 메타데이터 거부 회피)
- `pytorch-lightning~=1.7`, `torchmetrics==0.10.3`(`_compare_version`), `torch 1.13.1+cu117`(A100 OK), `six`/`protobuf`(tensorboard)
- lessac-medium 베이스: `hf download rhasspy/piper-checkpoints --repo-type dataset --include "en/en_US/lessac/medium/*.ckpt"`

## 권장치
- 73분 데이터 기준 **베이스(epoch 2164) + 1000~1800 epoch**(= epoch 3000~4000)가 스윗스팟. A100 ~2-3시간.
- loss 평탄해지면 더 돌려도 의미 없음. B 화자도 `--speaker B`로 동일.
