# 1. 로컬(노트북)에서 녹음 파일 처리하기

> 노트북(CPU)에서 할 수 있는 것: **녹음 → 화자분리 → 전사 → 데이터셋 + 방언 프로필**.
> 실제 목소리·말투 복제(모델 학습)는 GPU 필요 → [2번 문서](2_GPU에서_학습.md).

## 준비 (최초 1회)
```powershell
# 1) ffmpeg 설치 (없으면)
winget install Gyan.FFmpeg          # 설치 후 터미널 새로 열기

# 2) 가상환경 + 설치 (순서 지킬 것 — 버전 충돌 방지)
cd C:\Users\pjo12\Downloads\coding\callone
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
pip install torch torchvision torchaudio                       # CPU 일관 세트 먼저
pip install faster-whisper "pyannote.audio>=4.0" "speechbrain==1.0.2" "transformers>=4.55.2"
pip install "numpy<2.4"                                          # 반드시 마지막(numba/librosa 호환)

# 3) .env
Copy-Item .env.example .env
python -m callone.common.crypto genkey   # 출력값을 .env의 ENCRYPTION_KEY 에
notepad .env                              # HF_TOKEN=hf_... 넣기
```

## HF 토큰 + 게이트 동의 (무료, 1회)
1. huggingface.co → 토큰 발급(Read) → `.env`의 `HF_TOKEN`
2. 아래 두 페이지에서 "Agree" 클릭:
   - huggingface.co/pyannote/speaker-diarization-community-1
   - huggingface.co/pyannote/segmentation-3.0

## 실행
```powershell
# 녹음 m4a 파일들을 data\raw\ 에 넣은 뒤:
$env:PYTHONUTF8=1
python scripts/run_local_full.py
```
이 한 줄이 끝까지 다 함: 적재 → 복원 → 화자분리 → 전사(한국어) → A/B 연결 → 방언 프로필 → 데이터셋.
(중간에 멈춰도 같은 명령 다시 = 이어서 함. 노트북 절전 자동 방지.)

## 결과물
- `data/speakers/A/profile.json`, `B/profile.json` — 방언 지역·세기 자동측정 + 말투 통계
- `data/datasets/A/tts/`, `B/tts/` — 음성 학습셋
- `data/datasets/A/dialogue/`, `B/dialogue/` — 대화셋 + 페르소나 카드

## 참고
- CPU라 전사는 느리고(통화 261분 ≈ 1~2시간) 작은 모델(small)이라 좀 거칠다.
- 정확한 분리·전사·실제 학습은 GPU에서 → [2번 문서](2_GPU에서_학습.md).
