# 졸업전시 기획서 — 《call:one 콜론》 (3트랙)

산업디자인 졸업전시용 callone 전시 기획. 2026-07-13 개정 6판 — ③ 트랙을 TWIN(협력자 블라인드) →
**MAKER 《제작자》**(제작자 본인 클론과의 통화·생각 공유)로 전환. 트랙명 ECHO/PORTRAIT/MAKER 확정.
전제: 모든 참가자는 사전 동의 확보됨(본인 목소리·지참 녹음 모두). 윤리 리스크 논외.

전시 산출물(모두 `demo/`):
- **`demo/exhibit_deck.html`** — 지도교수 컨펌용 발표자료 (1280×720 9장, 피그마 html.to.design 임포트용).
- **`demo/callone_demo_v2.html`** — 3트랙 인터랙티브 데모 **아날로그 물성 판(현행)**. 상단 가로 툴바,
  좌=전화기(관람객 통화)·우=교환기(공중전화 부스형, 목소리 제작 파이프라인). 수화기·VU 계기·파일럿 램프·
  종이테이프 로그 등 아날로그 텔레포니 조형. ③ 트랙 = MAKER 《제작자》.
- **`demo/callone_demo.html`** — 초판(3열: 좌 참가자·중앙 코어·우 상대 목소리). v2로 대체됨(참고용).
  각 트랙이 수신 전화→통화(타이머·실시간 자막)→작별/선택/맺음까지 대사 전부 짜인 한 사이클로 재생.

## 0. 이름과 한 문장

**전시명 = call:one (콜론).** 프로젝트명을 그대로 가져간다 —
- call + clone 의 중의, 소리내면 문장부호 '콜론(:)'
- 콜론은 **말과 말을 잇는 기호**: 앞말이 끝나고, 잠시 멈추고, 뒷말이 온다 — 전화의 침묵과 응답 그 자체
- 워드마크 `call:one` — 가운데 콜론이 로고이자 상태등(연결 중엔 깜빡인다). **UI 구현됨.**
- 디자인 언어(UI 적용됨): 종이·잉크·수화기 주홍 1색, 세리프 제목 + 모노 상태표기, 서식형 셋업,
  말풍선 대신 **대본(transcript)** — 전화국 가입 서식/인쇄물의 결.

> **목소리는 10초면 온다. 말투는 한 통의 녹음, 기억은 백 시간.**

데이터가 쌓일수록 "그 사람"이 되어가는 과정을 세 번의 통화로 체험시킨다.
근거(벽면 텍스트 겸): 스탠퍼드 1,052명 연구 — 인구통계만 74% → 설문 82% → 인터뷰 결합 86%,
이후 수렴(asymptote). 데이터 축 = 충실도 축 = 전시 동선 축.

## 1. 전시 구조 = 3트랙

| | ① ECHO 《메아리》 | ② PORTRAIT 《음성 초상》 | ③ MAKER 《제작자》 |
|---|---|---|---|
| 데이터 | 현장 10초 녹음 + 1분 설문 | 녹음 파일 한 통(지참) | 제작자 발화 수십 시간 + 심층 인터뷰 |
| 목소리 | 제로샷(즉석) | 화자분리→최적 ref 추출 | 딥클론(다중 ref + 품질 선별) |
| 페르소나 | 설문→캐릭터 카드 즉석 생성 | 전사 기억 추출 + 관계 설문 | LoRA 말투 튜닝 + 제작자 생각 기억 RAG |
| 통화 상대 | 10년 뒤의 나 | 소중한 사람 | 이 전시를 만든 사람 |
| 운영 | 워크인 전원, 4분 회전 | 예약 슬롯(하루 4~6팀), 15분 | 사전 제작, 상시 통화 체험 |
| 끝맺음 | 소멸(카운터) | 소멸 or USB 반출 선택 | 제작자 서명(부재 증명) |

관람 동선 = 데이터 역순 진입: 입구에서 ③ 제작자의 통화를 목격 → ① 씨앗을 직접 체험 → ② 자기 것을 심고 감.
(혼잡 시 ①만 체험해도 완결되도록 각 트랙 독립 완결.)

## 2. 트랙 ① ECHO 《메아리》 — 10년 뒤에서 걸려온 전화 (메인, 워크인)

```
[동의·설문] 태블릿 90초: 동의 체크 → 설문 6문항
  ↓
[녹음] 수화기에 문장 낭독 10초 ("여보세요, 나야. 잘 지냈어?")
  ↓  ~15s: ref 세팅+워밍업, 설문→캐릭터 카드+memories 시드 생성
[벨] 전화가 울린다
  ↓
[통화] 90~120초. "10년 뒤 나" — 설문 답을 아는 상태로 말 걸어옴
  ↓
[작별] 시간 종료 → farewell 자동 → 마지막에 부메랑 연출(아래)
  ↓
[소멸] 조명 소등→리셋, 벽면 카운터 +1, 리플렉션 카드 1장
```

**설문 6문항** (연구 근거: GSS류 가치관 + TIPI 축약 + 개인 앵커):
1. 요즘 가장 큰 고민 하나 (단답)
2. 10년 뒤 나는 어디서 무엇을 하고 있을까 (한 문장)
3. 가장 아끼는 사람 (호칭만)
4. 성격 슬라이더 2개: 내향↔외향 / 신중↔즉흥
5. 요즘 나를 웃게 한 것
6. **10년 뒤 나에게 남기는 한마디** (자유 입력)

**부메랑 연출**: 6번 답을 클론이 작별 직전에 되돌려준다 —
"아 맞다. 네가 나한테 하고 싶은 말 있었잖아. …나도 너한테 똑같이 말해주고 싶었어."
설문이 곧 대본 재료가 되는 구조.

**설문→페르소나 구현 (`callone/llm/persona_survey.py`, 구현·테스트됨)**: LLM 불필요, 순수 템플릿.
`persona_from_survey(name, answers, mode)` →
- `card`: SessionInit 캐릭터 카드 필드와 1:1(persona/personality/situation/first_message/…) —
  슬라이더 2개는 성격 서술로 변환(내향↔외향, 신중↔즉흥), 고민은 background 로("나는 그 일이
  어떻게 되는지 안다")
- `memories`: "사용자는 …" 한 문장 배열 — memory_update 규약 그대로, 기존 RAG가 즉시 회상
- `boomerang`: 6번 답 기반 farewell 추가 지시문 — 작별 지시 뒤에 이어붙이면 끝
- `mode="loved_one"`(트랙②): 호칭·입버릇·놀리던 방식 → personality, 함께한 기억 → memories

**음성 추출(트랙①)**: 수화기 낭독 10초가 그대로 제로샷 ref. **낭독문을 우리가 정하므로
ref_text 를 이미 안다** — 전사 단계 생략(지연·오류 0), 텍스트-오디오 정합 100%로 유사도 최상.
낭독문 자체도 연출: "여보세요, 나야. 잘 지냈어?" — 첫 ref 가 곧 첫 대사.

회전율: 1인 ~4분, 시간당 12~15명. 부스 2기 운영 시 25~30명.

## 3. 트랙 ② PORTRAIT 《음성 초상》 — 한 통의 녹음 (예약제)

참가자가 소중한 사람과의 통화 녹음 파일 하나를 가져온다(USB/폰). 하루 4~6팀 예약.

```
[접수] 예약 확인 → 파일 투입
  ↓
[분석 3~5분] 화자분리→ref 후보 추출(voice_analyze 구현됨)
  — 대기시간 자체를 연출: "목소리를 찾고 있습니다" 파형 시각화 스크린
  ↓
[선택] 화자 카드에서 "이 목소리가 그 사람인가요?" 샘플 듣고 선택(구현됨)
  ↓
[관계 설문 2분] 태블릿 8문항: 서로 부르던 호칭 / 그 사람 말버릇·자주 하던 말 /
  함께한 기억 2~3개 / 마지막으로 나눈 대화 주제 / 그 사람이 나를 놀리던 방식
  ↓  전사 기억 자동 추출(memory_update) + 설문 → memories.json 병합
[통화] 3~5분. barge-in 허용, 시간 여유 있게
  ↓
[선택의 순간] "이 목소리를 가져가시겠습니까?"
  — 소멸(기본) or 본인 USB로 반출(구현된 export). 우리 쪽 보관은 어느 쪽이든 0
  ↓
[여운] 리플렉션 카드 + (동의 시) 한 줄 소감 벽면 게시
```

관계 설문의 역할: 전사에서 안 나오는 관계 고유 신호(호칭·장난)를 주입 — IMPersona 연구가
보인 "말투+개인지식 결합"이 지인 설득의 핵심이라는 결과를 그대로 적용.
구현: `persona_from_survey(name, answers, mode="loved_one")` (구현됨) + 화자분리→ref 추출은
기존 voice_analyze(SNR 60%+길이적합 40%, 6~12초 창) 그대로.

**파일 수신 방법 — 결론: QR → 로컬 Wi-Fi 업로드 (USB 폴백)**

| 방법 | 판정 | 이유 |
|---|---|---|
| **로컬 Wi-Fi AP + QR** ★채택 | 최적 | 부스 GPU 박스가 오프라인 핫스팟(라즈베리파이/공유기) → QR 스캔 → 브라우저 업로드 페이지. iPhone·Android 둘 다 됨, 앱 설치 0, 인터넷 불필요(오프라인 원칙 유지), 수백 MB도 Wi-Fi 속도로 OK. 기존 POST /api/voice/analyze 에 바로 붙음 |
| USB-C/A + SD 리더 | 폴백 | 보이스레코더·구형 폰 대응. 접수 데스크에 리더기 상비 |
| 블루투스 | 탈락 | iPhone 은 파일 전송(OBEX) 자체가 막혀 있음. Android 도 느림(수 MB/분) |
| AirDrop | 탈락 | 애플↔애플 전용 + 수신측 Mac 필요 |
| 인터넷 업로드(클라우드) | 탈락 | 오프라인 원칙 위반 + 전시장 회선 불신 + "이 방을 떠나지 않습니다" 서사 붕괴 |

업로드 페이지 = "이 파일은 이 방을 떠나지 않습니다" 문구와 함께 — 수신 방식까지 프라이버시
연출의 일부. m4a/mp3/wav 디코딩은 서버가 이미 처리(?ext= 파라미터).

## 4. 트랙 ③ MAKER 《제작자》 — 만든 사람에게서 온 전화 (사전 제작)

이 전시를 만든 사람(제작자 본인)의 완전한 클론. ①·②가 "관람객/그 사람"의 목소리라면 ③은
**제작자 자신을 딥클론**해, 관람객이 "만든 사람"에게 직접 전화를 건다. 통화가 곧 아티스트
스테이트먼트 — 왜 만들었는지, 목소리·기억·부재를 어떻게 보는지를 제작자의 목소리·말투·생각으로
들려주는 창. 전시의 논지를 전시 자신의 매체로 전달하는 메타 트랙(블라인드/튜링 테스트 아님).

**제작 파이프라인** (8~9월):
1. 녹음 수집: 제작자 일상 발화·낭독 수십 시간 → diarize → utterances/parquet
2. 심층 인터뷰: AVP 프로토콜 변형 2시간 — **callone 자신이 AI 인터뷰어**로 전화를 걸어 제작자를 인터뷰
   (제작 동기·전시 주제에 대한 생각을 기억으로 축적 — 통화에서 회상)
3. 말투: LoRA 튜닝(배선 완료) + 기억: memories 대량 구축 + RAG
4. 검증: bench + 본인 청취(목소리·생각 일치 확인)

**전시 형태**:
- **제작자 통화 체험**: 관람객이 제작자의 클론과 통화 — 신원은 처음부터 공개. "왜 만들었어요?"
  같은 물음에 제작자의 실제 생각으로 답하고, 앞의 두 트랙(ECHO·PORTRAIT)을 제작자가 되짚어 맺는다.
- **맺음(서명)**: "방금 당신은, 이 전시를 만든 사람과 통화했습니다 — 목소리와 생각 모두 제작자에게서,
  지금 제작자는 이 자리에 없습니다." → 전시 주제(부재해도 이어지는 목소리)를 제작자 자신으로 증명.
- (선택) 제작 노트/다큐: 제작 과정 + AI 인터뷰 장면.

③이 있어야 ①·②가 "시작"으로 읽히고, 동시에 제작자의 목소리가 전시 전체를 봉인한다 —
"백 시간이면 어디까지 가는가"를 만든 사람 자신이 증명하는 것이 전시의 논지.

## 5. 공간·물리 설치

| 요소 | 설계 |
|---|---|
| 배치 | 입구 ③ 제작자 통화 코너 → 중앙 ① 메인 부스(가능하면 2기) → 출구 측 ② 접수 데스크+부스 1기. ③ 통화 체험은 ② 부스를 오프피크 공유 |
| 부스 | 1인 반밀폐(1.2×1.2×2.2m), 흡음재, 반투명 외피(대기자에게 실루엣만) |
| 전화기 | **시대 그라데이션**: ① 현대 미니멀 핸드셋 → ② 90년대 가정용 무선전화기 → ③ 로터리 다이얼 — 데이터가 깊어질수록 기억도 오래된 물건으로. 셋 다 후크 스위치=트리거, USB 오디오 개조 |
| 조명 | 상태 연동(state 이벤트): 대기=호박색, 벨=점멸, 통화=따뜻한 백색, 소멸=소등→리셋 |
| 카운터 | 벽면: "오늘 ___개의 목소리가 태어나고 사라졌습니다" (①·② 합산) |
| 패널 | 데이터→충실도 그라데이션 그래프(74→82→86%), 파이프라인 다이어그램, 스테이트먼트 |

수화기 = 밀착 마이크 — 전시장 소음 문제를 형태가 해결.
